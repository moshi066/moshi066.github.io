# moshi066.github.io

Personal portfolio of Md Moshiur Rahman, Senior Software Engineer (.NET / C# · Go · Next.js).

Static site, no build step: `index.html`, `assets/css/style.css`, `assets/js/script.js`.
Motion is powered by GSAP + ScrollTrigger and Lenis (loaded from CDNs); the Codeforces card pulls live data from the public Codeforces API.

To preview locally, serve the folder with any static server, e.g. `python3 -m http.server 8080`.
